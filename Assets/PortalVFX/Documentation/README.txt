STYLIZED PORTAL VFX – 72 ANIMATED PORTALS  1.0.0
Unity 2022.3 LTS or newer  |  Built-in, URP, HDRP

Quick start
1. Tools > Portal VFX > Portal Browser
2. Pick a portal, press Place, press Play.
3. To walk through: select the portal + Self-link (or two portals + Link 2 portals),
   select your character + Make teleportable.

Start with the demo: Assets/PortalVFX/Demo/PVX_Demo_Main.unity (WASD, mouse, 1-9 travel).

Render pipelines
- Built-in: enable Soft Particles in Quality settings; use any bloom.
- URP: enable Depth Texture on the URP asset; camera Post Processing + Bloom volume.
- HDRP: use Fixed exposure (EV 0-2).
Demo scenes set up their post-processing automatically in every pipeline.

Full documentation: Documentation/PortalVFX_Documentation.pdf (or .html).
